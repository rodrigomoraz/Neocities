Reseña

Increíble lo profundo que puede ser un sistema de juego utilizando solo dos botones. Sencillo para aprender, pero con una complejidad que hace que realmente se note la diferencia en habilidad entre los jugadores cof cof Smash Bros cof cof.

La curva de aprendizaje es algo inclinada, se tienen diferentes vehículos que difieren en jugabilidad completamente y que se deben aprender por separado para poder dominarlos. Cada personaje tiene una habilidad especial única que también se debe dominar para aprovechar al máximo. Eso sin contar las estrategias de cada escenario que también se deben aprender para no andar arrastrando el prestigio en el multijugador. Lo cuál no quiere decir que el juego no se pueda disfrutar siendo principiante, como dije en un inicio, las mecánicas son bastante intuitivas y se puede ajustar la dificultad.

Hay distintos modos de juego que ofrecen variedad y rejugabilidad, desde carreras rápidas hasta batallas multijugador. No es Mario Kart, pero hay una comunidad activa de jugadores para que se puedan disfrutar en línea.

Las pistas, los personajes, los menús, la banda sonora, los efectos visuales y de sonido, todo tiene una dirección artística muy cuidada. Además se puede ajustar la UI para que se adapte al gusto de cada quién.

Exclusivo de Switch 2 para que valga la pena el gasto.
